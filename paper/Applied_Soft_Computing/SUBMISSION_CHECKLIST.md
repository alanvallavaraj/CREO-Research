## Author confirmation before submission

- [ ] Confirm the article type in Editorial Manager (normally Research Article).
- [ ] Confirm the title, author spelling, affiliation, corresponding email, and author order.
- [ ] Add the author's ORCID in Editorial Manager and to the LaTeX front matter if desired.
- [ ] Confirm funding information. If there was no funding, select the corresponding no-funding option in Editorial Manager.
- [ ] Confirm and submit the competing-interest declaration; do not infer or omit it.
- [ ] Decide whether to give editors/reviewers repository access now or upload a review archive with the submission.
- [ ] Add a permanent public repository release/DOI to the manuscript before publication.
- [ ] Upload `highlights.txt` separately using the Highlights item type.
- [ ] Upload `main.pdf` as the manuscript and the complete directory as LaTeX source when requested.
- [ ] Verify the PDF generated by Editorial Manager against the included `main.pdf`.

## Heading rule used

The manuscript uses only article-body `section` and `subsection` levels. The appendix uses `section` headings under `\appendix`, which is the standard CAS approach.
